# سلام في سوريا — Peace in Syria

منصة رقمية لبناء السلام: تقيس لغة النصوص قبل نشرها، تفنّد الشائعات، وتنشر محتوى يومياً يعزّز التهدئة والتعايش.
التطبيق **RTL بالكامل** بالعربية، وكل استدعاءات الذكاء الاصطناعي تجري على الخادم فقط.

---

## المكدّس التقني

| الطبقة | التقنية |
| --- | --- |
| الواجهة | React 18 + Vite 8 + React Router 7 |
| التنسيق | Tailwind CSS 3 (mobile-first, RTL) |
| الأيقونات | `lucide-react` |
| الخادم | Node.js + Express 5 (`server.ts` عبر `tsx`) |
| الذكاء الاصطناعي | `@google/genai` (Gemini) — على الخادم حصراً |
| التخزين | مصفوفات في الذاكرة داخل `server.ts` (نسخة MVP) |

`server.ts` هو نقطة الدخول الوحيدة: في التطوير يشغّل Vite في وضع الوسيط (`middlewareMode: true`)،
وفي الإنتاج يخدم مجلد `dist` الثابت. مسارات `/api/*` تُعالَج قبل Vite دائماً.

---

## التشغيل

```bash
npm install
cp .env.example .env      # ثم ضع مفتاح Gemini داخل الملف
npm run dev               # http://localhost:5173
```

للإنتاج:

```bash
npm run build             # يبني الواجهة إلى dist/
npm start                 # NODE_ENV=production + خدمة dist
```

### متغيرات البيئة

| المتغير | الوصف | الافتراضي |
| --- | --- | --- |
| `GEMINI_API_KEY` | مفتاح Gemini (يُقرأ على الخادم فقط) | — (مطلوب لميزات الذكاء الاصطناعي) |
| `GEMINI_MODEL` | اسم النموذج | `gemini-2.5-flash` |
| `PORT` | منفذ الخادم | `5173` |

> بدون المفتاح يعمل التطبيق بالكامل، لكن المسارات الذكية (المقياس، التحقق من الشائعات، توليد المنشورات)
> تُرجع الرمز `503` مع رسالة عربية واضحة تظهر في الواجهة كحالة خطأ مع زر إعادة المحاولة.
> المفتاح لا يُرسل إلى المتصفح في أي حال، ولا يظهر في حزمة الواجهة.

## واجهات API

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `GET` | `/api/status` | الحالة العامة: وضع الأزمة، تهيئة الذكاء الاصطناعي، وعدّادات المراجعة |
| `PATCH` | `/api/status` | تفعيل/تعطيل وضع الأزمة `{ crisisMode: boolean }` |
| `POST` | `/api/meter/analyze` | **AI** — تحليل نص: `isCalm`، `hasGeneralization`، `safetyScore`، `analysis`، `rewrittenText` |
| `GET` | `/api/posts` | المنشورات مع تصفية `status` و`category` و`q` |
| `POST` | `/api/posts/generate` | **AI** — توليد منشورات جديدة (تُحفظ بحالة `pending`) |
| `PATCH` | `/api/posts/:id` | اعتماد أو رفض منشور |
| `GET` | `/api/rumors` | قاعدة الشائعات المعتمدة مع بحث وتصنيفات |
| `POST` | `/api/rumors/verify` | **AI** — تقييم ادعاء: `status`، `category`، `correction`، `advice`، `credibilityScore` |
| `POST` | `/api/rumors` | إرسال شائعة من مستخدم (تُحفظ `pending`) |
| `GET` | `/api/stories` | القصص (`?status=approved` افتراضياً) |
| `POST` | `/api/stories` | إرسال قصة جديدة (`pending`) |
| `PATCH` | `/api/stories/:id` | نشر أو رفض قصة |
| `GET` | `/api/guidelines` | أسئلة الإرشادات وتصنيفاتها |
| `POST` | `/api/reports` | بلاغ عن محتوى تحريضي، يعيد رقماً مرجعياً |
| `GET` | `/api/reports` | قائمة البلاغات |

كل الأخطاء تُعاد بالشكل `{ "error": "رسالة بالعربية" }` مع رمز HTTP مناسب
(`400` تحقّق، `404` غير موجود، `429` تجاوز الحد، `503` الذكاء الاصطناعي غير مهيّأ، `504` مهلة).

## الصفحات

| المسار | الصفحة |
| --- | --- |
| `/meter` | مقياس لغة السلام — تحليل النص، مؤشر دائري، وصياغة بديلة قابلة للنسخ |
| `/today` | منشورات اليوم — بطاقات مع بحث، تصنيفات، حجم خط، حفظ في `localStorage`، ومشاركة |
| `/rumors` | شائعة وتصحيح — تحقق فوري + قاعدة شائعات + نموذج إرسال |
| `/stories` | قصص إيجابية — عرض القصص المعتمدة فقط + نموذج إرسال |
| `/guidelines` | إرشادات عامة — أكورديون مع بحث وتصنيفات |
| `/report` | الإبلاغ عن كراهية — نموذج من ثلاث خطوات مع محاكاة رفع لقطة شاشة |
| `/dashboard` | لوحة التحكم — مراجعة المنشورات والقصص + مفتاح وضع الأزمة |

## ملاحظات

- **المراجعة البشرية:** كل منشور مولَّد بالذكاء الاصطناعي وكل قصة واردة تبدأ بحالة `pending`
  ولا تظهر للجمهور قبل اعتمادها من لوحة التحكم.
- **وضع الأزمة:** عند تفعيله يتغيّر توجيه المطالبة (prompt) نحو التهدئة والتحقق، ويظهر تنبيه في كل الصفحات.
- **التخزين:** البيانات في الذاكرة وتُفقد عند إعادة تشغيل الخادم — استبدلها بقاعدة بيانات قبل أي استخدام حقيقي.
- **رفع الصور:** في نموذج البلاغ يُسجَّل اسم الملف فقط (محاكاة واجهة)، ولا تُرفع أي صورة إلى الخادم.
