# الإعلام الرقمي

أداة فرز محتوى (Trust & Safety) تستخرج منشورات صفحات فيسبوك وتغريدات X
عبر واجهة Apify، ثم تصنّفها محلياً على إطار قانوني وأخلاقي سوري.

**تعمل من القرص مباشرةً** — نقرة مزدوجة على `index.html`. لا خادم، ولا
عملية بناء، ولا اتصال بالإنترنت للواجهة نفسها.

## من أين تبدأ

| | |
|---|---|
| **`digital-media-v6/index.html`** | النسخة الحيّة — افتحها بالمتصفّح |
| `digital-media-android/` | غلاف أندرويد (Capacitor) — التفاصيل في `README` الخاصّ به |
| `facebook-extractor/` | الإصدار الخامس، محفوظ للمقارنة ولا يُطوَّر |
| `docs/architecture.html` | المواصفة المعمارية — تُفتح بالمتصفّح كذلك |
| **`AGENTS.md`** | **قواعد المشروع — اقرأه قبل أي تعديل** |

## التطوير

كل تعديل في `digital-media-v6/`. لا اعتماديات ولا خطوة بناء:

```bash
cd digital-media-v6
node --test "tests/*.test.js"     # 162 اختباراً
```

ثم لنقل التعديل إلى تطبيق أندرويد:

```bash
cd ../digital-media-android && npm run sync
```

## قاعدة البيانات المحلية (اختيارية)

أرشفة النتائج على الجهاز:

```bash
cd digital-media-v6 && npm run db
```

أو على ويندوز: `local-server/START-DATABASE.bat`.

## ما يجب ألّا يُكسر

المشروع محكوم بقيد واحد يشتقّ منه كل قرار: **يُفتح من `file://` وقد يعمل
بلا إنترنت**. لا CDN، ولا خطوط بعيدة، ولا وحدات ES، ولا خطوة بناء، ولا
إطار عمل. التفاصيل والأسباب في `AGENTS.md`.
