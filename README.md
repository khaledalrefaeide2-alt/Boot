# Boot

مستودع يضم مشروعين منفصلين:

## `platform/` — منصة رصد وتحليل المنصات الإعلامية

النظام الأساسي: تطبيق Next.js داخلي لرصد وتحليل حسابات فيسبوك وإكس وإنستغرام
عبر Apify، بواجهة عربية RTL كاملة ولوحة إدارة وصلاحيات وأدوار.

التفاصيل الكاملة في [`platform/README.md`](platform/README.md).

```bash
cd platform
cp .env.example .env    # ثم عدّل القيم
docker compose up -d --build
```

## `facebook-extractor/` — الموقع الثابت السابق

النسخة الأولى: ثلاث صفحات HTML ثابتة تستدعي Apify من المتصفح مباشرة، مع خادم
SQLite محلي اختياري. تبقى كما هي للرجوع إليها، ولا علاقة لها بالنظام الجديد.
