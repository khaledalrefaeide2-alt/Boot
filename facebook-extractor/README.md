# سلام — منصة رصد منشورات التحقق

<img src="assets/salam-mascot.svg" width="120" align="left" alt="سلام">

موقع ويب يرصد منشورات صفحات **منصات التحقق** على فيسبوك آلياً — كل نصف ساعة — عبر الربط بمفتاح
[Apify Facebook Posts Scraper](https://apify.com/apify/facebook-posts-scraper)، ويعرضها بواجهة تعكس
قيمتَي **الشفافية** و**الموثوقية** في هوية سلام الرقمية.

<br clear="left">

## البنية

| الملف | الوظيفة |

## الأقسام

### 🛰️ الرصد الآلي
غرفة تحكّم تعرض مدة الدورة وآخر دورة والدورة القادمة وعدد المنصات المفعّلة، مع عدّاد تنازلي حيّ في الشريط العلوي.
- **دورة كل ٣٠ دقيقة** افتراضياً (قابلة للتغيير: ١٥ دقيقة ← ١٢ ساعة).
- **رصد فوري** خارج الدورة بضغطة واحدة.
- **دورة تعويضية**: عند فتح الموقع بعد انقطاع، تُنفَّذ الدورة فوراً إذا انقضى وقتها.
- **استخراج مخصّص**: منصة واحدة أو الجميع، بعدد منشورات وفترة زمنية محددة.

### 📰 المنشورات
بطاقات احترافية لكل منشور: اسم المنصة وشارة المصدر المسجّل، وقت النشر ووقت الرصد، النص كاملاً (مع طيّ/فرد)،
الوسائط، الإعجابات والتعليقات والمشاركات، ورابط المصدر الأصلي.
بحث فوري، تصفية حسب المنصة والفترة الزمنية والوسائط، فرز بخمسة معايير، وتصدير JSON / CSV.

### 📊 التحليلات
نشاط النشر خلال ١٤ يوماً (رسم بياني)، التفاعل وحجم النشر حسب المنصة، أعلى ٥ منشورات تفاعلاً، ومؤشرات عامة
تشمل نسبة نجاح دورات الرصد.

### ⚙️ لوحة التحكم
- **الربط بحساب Apify**: يُتحقَّق من المفتاح فور حفظه ويُعرض اسم الحساب.
- **منصات التحقق**: إضافة فردية أو جماعية، تصنيف المصدر (منصة تحقق / وكالة أنباء / جهة رسمية / أخرى)،
  تفعيل وتعطيل الرصد لكل منصة، وحذفها دون فقد منشوراتها.
- **إعدادات الرصد**: مدة الدورة، عدد المنشورات لكل منصة، البدء التلقائي، إشعارات المتصفح.
- **قاعدة البيانات المحلية** والنسخ الاحتياطي (تصدير/استعادة كل البيانات بملف واحد).

### 🧾 سجل الشفافية
كل دورة رصد — ناجحة أو فاشلة — تُسجَّل بوقتها والمنصات المشمولة وعدد العناصر المجلوبة والجديدة ومدتها
ومعرّف التشغيل في Apify وسقف الفوترة المفروض عليه.

## طريقة الاستخدام

1. افتح `index.html` في المتصفح (أو انشره على أي استضافة ثابتة مثل GitHub Pages).
2. من **لوحة التحكم** ← أدخل مفتاح Apify من [Apify Console ← Settings ← Integrations](https://console.apify.com/settings/integrations).
3. أضِف روابط صفحات منصات التحقق التي تريد رصدها.
4. اضغط **تشغيل الرصد الآلي** — وستصل المنشورات كل نصف ساعة تلقائياً.

## الهوية البصرية

مستمدة من شخصية سلام مباشرة: **قرمزي الطربوش** (`#A3182A`) للهوية، **ذهبي الزخارف** (`#C9A031`) للعناوين والإجراءات
الأساسية، **سماوي التوهّج** (`#3FD8E6`) لحالات الرصد الحيّ والروابط، و**لؤلؤي الهيكل** (`#F2E9D8`) للنصوص.
الخلفية حبرية داكنة (أو لؤلؤية في الوضع الفاتح) — **خلفية الشخصية البيضاء غير مستخدمة كلون سطح إطلاقاً**،
وتزيّن الصفحة زخرفة النجمة الثمانية المأخوذة من شعار صدر سلام.

## ملاحظات تقنية

- الموقع **ثابت بالكامل** (HTML/CSS/JS بلا مكتبات خارجية) — كل الطلبات تذهب من متصفحك إلى `api.apify.com` مباشرة،
  ولا يمرّ المفتاح ولا البيانات بأي خادم وسيط.
- الرصد يعمل ما دامت الصفحة مفتوحة (لا خادم خلفي دائم).
- 🛡️ **حماية من الاستهلاك الزائد**: يُمرَّر عدد المنشورات المطلوب إلى Apify كسقف فوترة إلزامي (`maxItems`)،
  فلا تتجاوز كلفة أي تشغيل (العدد × عدد المنصات) مهما جمعت الأداة.
- التخزين في ذاكرة المتصفح المحلية بسقف ٣٠٠٠ منشور، بلا تكرار — المنشور المكرَّر تُحدَّث أرقام تفاعله فقط.
- الصفحتان `monitor.html` و`dashboard.html` صارتا تحويلاً إلى الواجهة الموحّدة الجديدة.
