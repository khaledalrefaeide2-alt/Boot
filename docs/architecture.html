01الرؤية الاستراتيجية

ما الذي يخدمه هذا المنتج، وما القيد الذي يحكم كل قرار بعده

الأداة تستخرج منشورات صفحات فيسبوك وتغريدات X وتصنّفها على إطار قانوني وأخلاقي سوري. مستعملها مسؤول محتوى يمرّ على عشرات المنشورات في الجلسة الواحدة ويحتاج أن يقرأ الحكم بنظرة، لا أن يُبهَر. من هنا تنبع المعادلة كلها: الكثافة المعلوماتية أولاً، والعمق البصري في خدمتها لا فوقها.

القيد الحاكم: التشغيل من file://

الموقع يُفتح بالنقر المزدوج على ملف HTML من سطح المكتب. لا خادم، ولا عملية بناء، ولا شهادة، وقد لا يكون هناك إنترنت أصلاً. هذا ليس تفضيلاً بل شرط الاستعمال، وهو يُبطل طبقة كاملة من الحلول الشائعة.

القرار المعماري

المواصفة المطلوبة نصّت على Next.js أو Astro أو SvelteKit مع Three.js وTailwind وZustand. لا واحد منها يعمل تحت هذا القيد. أُطر التوليد تفترض خادماً أو خطوة بناء ومسارات جذرية تنكسر على البروتوكول المحلي؛ ووحدات ES تفشل بسياسة المصدر نفسه من file://؛ وTailwind يحتاج مرحلة ترجمة؛ وThree.js يعني إمّا CDN — أي طلباً خارجياً — وإمّا ~600KB مضافة إلى المستودع لطبقة زخرفية واحدة.

الذي نُفّذ بدلاً منها يحقّق الغاية المعلنة لا الوسيلة المسمّاة: HTML وCSS وJS عادية، نظام رموز مركزي بديلاً عن Tailwind، وحدات على window بديلاً عن Zustand، وWebGL مكتوب باليد في 10KB بديلاً عن Three.js. النتائج المرصودة أدنى من كل السقوف المطلوبة.

ثلاثة مبادئ تحكم الواجهة

  • الحكم قبل المحتوى. تصنيف المنشور يظهر في رأس البطاقة لا في جسمها، فتُمسح الشبكة كلها بنظرة واحدة قبل قراءة أي نصّ.
  • اللون الدلالي محجوز. الأخضر والكهرماني والأحمر ملك محرّك التصنيف وحده. لهذا لون الهوية سماوي — كي لا ينافس دلالةً على معناها.
  • العمق يُحسّ ولا يُقرأ. الزجاج والظلّ والميل ثلاثي الأبعاد تعطي ترتيباً للطبقات؛ متى طلبت انتباهاً لنفسها فقد فشلت.

خطأ قِيس وصُحّح

‏gl_FragCoord.y صفرها في أسفل الشاشة لا أعلاها. التخميد المكتوب على أساس العكس وضع أقوى الأثر خلف الفقرات بدل رأس الصفحة، فهبط تباين فقرة الميزات إلى 4.75:1 — فوق حدّ AA لكن بهامش لا يكفي خلفيةً متحرّكة. بعد عكس التخميد صار 5.35:1، وأدنى قياس على الصفحة كلها 5.36:1 عبر عشر لحظات متتابعة في المظهرين. الخلفية المتحرّكة لا تُقاس بلقطة واحدة.

backdrop.js · fragment shader
// الالتواء المجالي: نزيح الإحداثيات بضجيج آخر قبل أخذ الارتفاع،
// فتنكسر الاستقامة وتظهر أشرطة منسابة بدل بقع متكررة
float height(vec2 uv){
  vec2 q = vec2(fbm(uv + uT * 0.03), fbm(uv + vec2(5.2, 1.3) - uT * 0.02));
  return fbm(uv + 1.6 * q);
}

void main(){
  vec2 uv = gl_FragCoord.xy / uRes;
  vec2 sv = uv * vec2(uRes.x / uRes.y, 1.0) * 2.4;

  // اتجاه السطح من فروق منتهية — هذا ما يعطي الحجم بدل لطخة لونية
  float h = height(sv);
  float e = 1.6 / uRes.y * 2.4;
  vec3 n = normalize(vec3(height(sv + vec2(e, 0.0)) - h,
                          height(sv + vec2(0.0, e)) - h, e * 1.6));

  vec3  L    = normalize(vec3(-0.45, 0.7, 0.55));
  float lam  = max(dot(n, L), 0.0);
  float spec = pow(max(dot(reflect(-L, n), vec3(0.0, 0.0, 1.0)), 0.0), 22.0);

  vec3 col = mix(uA, uB, clamp(h * 0.85 + lam * 0.5, 0.0, 1.0));
  col += spec * 0.16;

  // انتبه: gl_FragCoord.y صفرها في الأسفل. عكسها يضع أقوى الأثر خلف الفقرات
  float fade = smoothstep(0.0, 0.86, uv.y)
             * smoothstep(0.0, 0.35, 1.0 - abs(uv.x - 0.5));
  gl_FragColor = vec4(col, clamp(uAmp * fade, 0.0, 1.0));
}

‏هـ · تفادي الفحص المسبق للطلبات

‏POST بترويسة Content-Type: application/json ليس طلباً بسيطاً، فيسبقه OPTIONS. ومن file:// يُرسل المتصفح Origin: null فيُرفض الفحص وتفشل كل عملية استخراج بـ «Failed to fetch». الحلّ إرسال نفس الجسم بنوع بسيط، مع تراجع إلى JSON إن رفضته الخدمة.

common.js
async function apiPost(url, body) {
  const payload = JSON.stringify(body);
  // text/plain طلب بسيط: لا OPTIONS، فلا رفض من أصل null
  let r = await apiFetch(url, { method: 'POST', body: payload,
    headers: { 'Content-Type': 'text/plain;charset=UTF-8' } });
  if (r.status === 400 || r.status === 415) {
    r = await apiFetch(url, { method: 'POST', body: payload,
      headers: { 'Content-Type': 'application/json' } });
  }
  return r;
}
