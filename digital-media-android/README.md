# الإعلام الرقمي — نسخة أندرويد

غلاف أصلي يحمل الإصدار السادس من الأداة داخل تطبيق أندرويد. النسخة
إضافية: `facebook-extractor` (الإصدار 5) و`digital-media-v6` باقيان كما
هما، وهذا المجلد لا ينسخ منطقاً بل يشير إلى الإصدار السادس ويزامنه.

## ما يحتاجه البناء

| | |
|---|---|
| **Node.js** | 18 فأحدث — لتثبيت الاعتماديات ومزامنة الأصول |
| **Android Studio** | الإصدار Ladybug فأحدث (يجلب حزمة SDK وGradle معه) |
| **JDK 21** | يأتي ضمن Android Studio |

> **لم يُبنَ ملف APK هنا.** حزمة أدوات أندرويد (`dl.google.com`) محجوبة في
> بيئة التطوير التي أُنشئ فيها المشروع، فتعذّر التصريف. كل ما عدا خطوة
> التصريف مُعدّ ومُختبَر؛ الخطوات أدناه تُنتج الملف على جهازك.

## البناء — أربع خطوات

```bash
cd digital-media-android
npm install          # مطلوب: مشروع Gradle يشير إلى node_modules/@capacitor/*
npm run sync         # ينقل طبقة الويب من digital-media-v6 ثم يزامن المشروع
npm run open         # يفتح المشروع في Android Studio
```

ثم من Android Studio: **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.
يخرج الملف في `android/app/build/outputs/apk/debug/app-debug.apk`.

للبناء من سطر الأوامر بدل الواجهة:

```bash
cd android && ./gradlew assembleDebug
```

نسخة الإصدار (موقَّعة) تحتاج مفتاح توقيع تُنشئه من
**Build ← Generate Signed Bundle / APK**.

## تحديث التطبيق بعد أي تعديل على الويب

طبقة الويب مصدرها الوحيد `digital-media-v6`. بعد أي تعديل هناك:

```bash
npm run sync
```

`www/` نسخةٌ لا مصدر — لا تُحرَّر يدوياً إلا `android.js` و`android.css`،
وهما وحدهما ما يخصّ الغلاف ولا يُنسخ فوقهما.

## ما أضافه الغلاف

‏WebView ليس متصفّحاً كاملاً. أربعة أشياء يعطيها المتصفّح مجاناً وتحتاج
كتابةً صريحة، وإلا بدت الميزة سليمةً وهي معطّلة:

| | المشكلة | الحلّ |
|---|---|---|
| **الحفظ** | `<a download>` لا يفعل شيئاً في WebView؛ التصدير يبدو ناجحاً بلا ملف | يُكتب الملف في ذاكرة التطبيق ثم تُعرض ورقة المشاركة ليختار المستخدم وجهته |
| **الروابط الخارجية** | `target=_blank` يفتح داخل الغلاف بلا شريط عنوان ولا رجوع، فيحتجز المستخدم | تُفتح في متصفّح النظام |
| **زرّ الرجوع** | يخرج من التطبيق فوراً ولو كان الدرج مفتوحاً | يغلق الدرج، ثم النافذة، ثم يرجع في التاريخ، ثم يخرج |
| **شريط الحالة** | الصفحة تمتدّ تحته فيقتطع من رأسها | تُحجز مساحته، ولونه يتبع مظهر التطبيق |

وتعديلات لمسية في `android.css`: إلغاء حالات المرور العالقة على الشاشة
اللمسية، ومنع تحديد نصّ الواجهة (ويبقى نصّ المنشور قابلاً للنسخ)، ومنع
السحب لتحديث الصفحة.

## ما لم يتغيّر

- **صفر طلبات شبكة للواجهة.** كل الأصول داخل التطبيق. الشبكة تُستعمل
  لواجهة الاستخراج وحدها، وهي ما جاء المستخدم من أجله.
- **المفاتيح** تبقى في التخزين المحلي للتطبيق ولا تغادره.
- **محرّك التصنيف** كما هو حرفاً بحرف.
