# مخزن مصغّرات الوسائط

## المشكلة

روابط صور فيسبوك وإنستغرام **موقّعة وتنتهي صلاحيتها**: في الرابط معاملان
`oh` (توقيع) و`oe` (وقت الانتهاء)، ومدّته ساعات إلى أيام. وكنّا نخزّن
الرابط وحده، فالمنشور بعد أسبوع يحمل رابطاً ميتاً ويظهر «تعذّر عرض
الوسائط».

والمنصة أرشيفٌ يمتدّ سنوات. وأرشيفٌ بلا صور نصفُ أرشيف.

## الحل

تُجلب الصورة **عند الاستيراد** — وهي اللحظة الوحيدة التي يكون فيها الرابط
حيّاً بيقين — وتُحفظ مصغّرةً (عرض 480 بكسل، WebP بجودة 72، نحو 30 كيلوبايت).
وما بعدها لا يعني انتهاءُ الرابط شيئاً.

| | |
| --- | --- |
| المكان | مجلّد Docker مشترك بين التطبيق والعامل (`MEDIA_DIR`، افتراضه `/app/media`) |
| المفتاح | بصمة الرابط — فالصورة المشتركة بين منشورات تُحفظ مرة |
| التقديم | `/api/media/<key>` بصلاحية الاطلاع، وتخزين مؤقت دائم في المتصفّح |
| السقف | `MEDIA_MAX_MB` (افتراضه 2048)، يُقلَّم كل ست ساعات والأقدمُ وصولاً أولاً |

الصورة تُعرض من المخزن، وتسقط إلى المصدر عند غيابه — منشورٌ استُورد قبل
المخزن، أو صورةٌ تعذّر جلبها، أو ملفٌ حُذف في التقليم. وفشلُ المخزن ليس
نهائياً: يُجرَّب المصدر قبل أن يُعلن العجز.

## لماذا كانت «تعذّر عرض الوسائط» تنتشر

المصغّرة كانت تُجلب **مرّةً واحدة**: عند الاستيراد، بسقف أربعمئة منشور في
التشغيل، وبلا إعادة محاولة أبداً. فثلاثة تسرّبات تُنتج العَرَض نفسه:

| التسرّب | ما كان يقع |
|---|---|
| تشغيل جلب ٥٠٠ منشور | مئةٌ منها **لم تُحاوَل أصلاً** |
| صورة تعثّر جلبها لحظتها | **لا يُعاد إليها أبداً** |
| ملف حذفه التقليم | المفتاح باقٍ **يشير إلى لا شيء** |

وفي الحالات الثلاث يظهر المربّع الرمادي نفسه، ولا يعرف أحد أيّها وقع. وحين
يُكتشف النقص يكون رابط المنصة قد انتهت صلاحيته — فلا استرجاع.

### والتقليم كان يأكل الحيّ قبل الميّت

مفتاح الصورة كان بصمةَ رابطها **الموقَّع**، ورابط فيسبوك يتغيّر توقيعه مع
كلّ استخراج. فالصورة الواحدة كانت تُحفظ مرّةً بعد كلّ تشغيل تحت مفتاح
جديد، وتبقى نُسَخها القديمة على القرص لا يشير إليها أحد.

ثم يأتي التقليم فيرتّب الملفّات بآخر قراءة ويحذف الأقدم — بلا أن يسأل
أيُّها ما زال مستعمَلاً. فيحذف مصغّرةً حيّة معروضة في بطاقة، ويُبقي عشر
نُسَخ ميتة من صورةٍ أخرى.

## ما يمنع تكرارها

1. **مفتاح لا يتغيّر بتغيّر التوقيع** — `canonicalMediaUrl` تُسقط `oh` و`oe`
   و`_nc_*` وأمثالها، وتُبقي `stp` و`name` و`format` لأنّها تحدّد المقاس
   والصيغة. فالصورة الواحدة ملفٌّ واحد مهما أُعيد استخراجها.
2. **مكنسة كل أربع دقائق** — أقصر المكانس دورةً، لأنّ ما تلاحقه يموت: رابط
   المنصة الموقَّع يعيش ساعات، فالمنشور الذي يُستورد الآن تُنقذ صورته الآن
   أو لا تُنقذ. وتلتقط كلّ منشورٍ بلا مفتاح، **الأحدث أوّلاً** — ترتيب
   إنقاذٍ لا عرض.
3. **عدّاد محاولات** (`mediaAttempts`) — بدونه تعود المكنسة في كلّ دورة إلى
   عشرات الآلاف من الروابط الميتة فلا تبلغ الحيّ منها. والفشل نوعان:
   `410`/`403` رابطٌ ميت يخرج **من أوّل مرّة**، و`429`/`5xx` وانقطاع الشبكة
   يُعاد إليها حتى الحدّ.
4. **التقليم يحذف اليتيم قبل المستعمَل** — ويقرأ المفاتيح الحيّة من القاعدة
   لا يخمّنها. وما يُخرَج حيّاً يُفرَّغ مفتاحه في الصفّ (فلا حالة كاذبة تقول
   «صورتي محفوظة» والقرص يقول لا) وتُرفع محاولاته إلى الحدّ — وإلا دار
   القرص في حلقة: يُجلب فيمتلئ، فيُقلَّم فيُجلب.
5. **إخراج الحيّ يُعلَن تحذيراً** في سجلّ العامل مع اسم `MEDIA_MAX_MB`:
   حذفُ اليتيم تنظيف، وحذفُ المستعمَل فقدٌ في الأرشيف لا يجوز أن يمرّ في
   سطرٍ عادي.

### الإعدادات

في `/admin/settings` تحت «البيانات»:

| المفتاح | الافتراضي | ما يفعل |
|---|---|---|
| `media.autoCache` | `true` | تشغيل المكنسة |
| `media.batch` | `120` | صور الدورة الواحدة |
| `media.maxAttempts` | `4` | بعدها يُترك المنشور بلا صورة |

## الأوامر

```bash
# حالة المخزن بلا جلب شيء — ابدأ بها دائماً
./deploy/dc.sh exec app npm run media:cache -- --status

# تعجيل ما ينتظر بدل انتظار المكنسة
./deploy/dc.sh exec app npm run media:cache -- --limit 5000
./deploy/dc.sh exec app npm run media:cache -- --days 30

# إعادة فتح ما استُنفدت محاولاته (قرصٌ امتلأ ليلةً، أو منفذٌ كان محجوباً)
./deploy/dc.sh exec app npm run media:cache -- --retry-gone --days 7
```

`--status` يقول أين انقطعت السلسلة: كم منشوراً له صورة، وكم منها محفوظ
عندنا، وكم ينتظر، وكم استُنفدت محاولاته.

**وما انتهت صلاحية رابطه لا سبيل إليه** إلا بإعادة استخراج حسابه —
والاستخراج التاريخي يُصلحه مع ما يجلب. `--retry-gone` يفتح الباب، ولا
يُحيي رابطاً ميتاً.

## حدود مقصودة

- **صورة واحدة لكل منشور** — صورةُ بطاقته لا ألبومه كلَّه. منشورٌ بعشر صور
  يضاعف المساحة عشراً مقابل صورٍ لا تُفتح إلا حين يفتح المراجع المنشور
  نفسه. فالأولى تصمد بعد انتهاء الرابط، والبقية تتبع مصدرها.
- **مصغّرة لا أصل** — 480 بكسل تكفي البطاقة والشبكة. وعارض ملء الشاشة يفتح
  المصدر الأصلي حين يكون حيّاً.
- **لا فيديو** — الملف الواحد عشرات الميجابايتات، ولا يُعرض في البطاقة أصلاً.

## الأمان

المخزن يفتح بابين، وكلاهما محروس ومُختبَر في `npm run verify:media`:

1. **الخادم صار يطلب روابط تأتيه من المشغّل.** فالوجهة مقيّدة بقائمة
   مضيفات (`fbcdn` · `cdninstagram` · `twimg` · `licdn` · `akamaihd`).
   بدونها يصير رابطٌ إلى `169.254.169.254` بابَ بيانات المزوّد، ورابطٌ إلى
   `postgres:5432` مسّاً بالقاعدة من الداخل.
2. **الخادم صار يقرأ ملفات بمفاتيح تأتيه من المتصفّح.** فالمفتاح يجب أن
   يطابق `^[a-f0-9]{40}$` قبل أن يُبنى به مسار — وإلا صار `../../` طريقاً
   إلى أي ملف تقرؤه الحاوية.

وهناك سقف تحميل (12 ميجابايت) ومهلة (12 ثانية) وتزامن أربعة طلبات: التسلسل
يجعل مئة صورة دقيقتين، والتوازي المفتوح يفتح مئة مقبس على خوادم المنصة
دفعةً فتُبطئ أو تحجب.
