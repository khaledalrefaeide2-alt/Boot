# المساعد الذكي — دليل التشغيل

وحدة تتيح للموظف محادثة المنصة وسؤالها عن بيانات الرصد المخزَّنة. الإجابات
مبنية على المنشورات الموجودة فعلاً في قاعدة البيانات، ضمن نطاق الحسابات
المسموح به للمستخدم وحده.

---

## 1. الحصول على مفتاح OpenAI

1. ادخل إلى <https://platform.openai.com/api-keys>
2. اضغط **Create new secret key**
3. انسخ المفتاح فوراً — لا يُعرض مرة ثانية
4. تأكّد من وجود رصيد في <https://platform.openai.com/settings/organization/billing>

---

## 2. أين يوضع المفتاح

في ملف `.env` على **الخادم** وحده:

```env
OPENAI_API_KEY=sk-...
OPENAI_CHAT_MODEL=gpt-4o-mini
OPENAI_EMBED_MODEL=text-embedding-3-small
```

### ⚠ تحذير أمني

**لا تضع المفتاح في أي متغيّر يبدأ بـ `NEXT_PUBLIC_`.**

وهذا ليس تشدّداً: كل متغيّر بتلك البادئة يُحقن في حزمة JavaScript التي
يحمّلها المتصفّح، فيصير المفتاح مقروءاً لأي شخص يفتح أدوات المطوّر — بما
فيهم من لا يملك حساباً على المنصة أصلاً. ومفتاح مسرَّب يعني فاتورة على
حسابك يدفعها غيرك.

في هذه الوحدة، المفتاح يُقرأ في الخادم فقط:

- كل ملف يلمسه يبدأ بـ `import 'server-only'` — استيراده من مكوّن عميل
  يُفشل البناء بدل أن يُحزَم المفتاح بصمت.
- صفحة المساعد تمرّر إلى الواجهة قيمة منطقية واحدة: **هل ضُبط المفتاح؟**
  لا المفتاح نفسه ولا جزءاً منه.
- مسار الاختبار لا يُعيد المفتاح ولا بادئته ولا طوله.
- رسائل أخطاء المزوّد لا تصل إلى المستخدم كما هي، بل تُصنَّف وتُعاد
  بنصّ عربي مكتوب عندنا — فلا يتسرّب معرّف حساب أو تفصيل إعدادات.

## 3. متغيّرات البيئة

| المتغيّر | إلزامي | الافتراضي | ملاحظات |
|---|---|---|---|
| `OPENAI_API_KEY` | نعم | — | خادميّ بحت |
| `OPENAI_CHAT_MODEL` | لا | `gpt-4o-mini` | يُغيَّر بلا تعديل شيفرة |
| `OPENAI_EMBED_MODEL` | لا | `text-embedding-3-small` | تغييره يستلزم إعادة فهرسة |

## 4. التشغيل

```bash
# 1) الترحيل — ينشئ جداول المحادثات والرسائل والمتّجهات
npm run db:deploy

# 2) توليد المتّجهات لأول مرة
npm run reindex:embeddings

# 3) تشغيل الخدمة
npm run dev
```

على الخادم:

```bash
cd ~/Boot/platform && git pull
./deploy/dc.sh up -d --build
./deploy/dc.sh exec app npm run reindex:embeddings
```

ثم افتح **الرصد ← المساعد الذكي**.

## 5. اختبار المفتاح

من حساب يملك صلاحية `settings.manage`:

```bash
curl -X POST https://<النطاق>/api/admin/ai/test \
  -H "x-csrf-token: <الرمز>" --cookie "mm_session=<الجلسة>"
```

النجاح:

```json
{
  "success": true,
  "chatModel": "gpt-4o-mini",
  "embedModel": "text-embedding-3-small",
  "message": "تم الاتصال بـ OpenAI بنجاح"
}
```

المسار يختبر المحادثة والمتّجهات معاً، ولا يُظهر أي جزء من المفتاح.

## 6. إعادة توليد المتّجهات

```bash
npm run reindex:embeddings                # الناقص فقط
npm run reindex:embeddings -- --all       # الكلّ من جديد
npm run reindex:embeddings -- --days 30   # آخر 30 يوماً
```

**متى تلزم `--all`؟** عند تغيير `OPENAI_EMBED_MODEL`. المتّجه الناتج عن
نموذج يختلف بُعده ومعناه عن نموذج آخر، ومقارنة متّجه من هذا بمتّجه من ذاك
تعطي رقماً بلا دلالة. والسكربت يحذف غير المتوافق تلقائياً قبل أن يبدأ.

المنشورات الجديدة لا تُفهرَس تلقائياً بعد — شغّل الأمر دورياً (مثلاً من
cron يومياً) أو بعد كل استخراج كبير.

## 7. ملاحظة تقنية: لماذا لا pgvector؟

المواصفة الأصلية طلبت `CREATE EXTENSION vector` والعامل `<=>`. وصورة
Postgres المستعملة في هذا المشروع هي `postgres:16-alpine` ولا تحمل ذلك
الامتداد، فالأمر يفشل.

فالمتّجهات تُخزَّن `double precision[]` ويُحسب جيب التمام في SQL. وتُخزَّن
**مُوحَّدة الطول (L2)**، فيصير جيب التمام ضربَ نقطةٍ بحتاً — جمعَ حواصل
ضربٍ بلا جذر ولا قسمة. والتكلفة تُحكَم بالتصفية المسبقة: النطاق، ثمّ
النافذة الزمنية، ثمّ سقف مرشّحين (3000).

**للانتقال إلى pgvector لاحقاً:** يلزم تغيير الصورة إلى
`pgvector/pgvector:pg16`. وانتبه — تلك الصورة مبنية على Debian لا Alpine،
والانتقال بين قاعدتَي glibc وmusl على مجلد بيانات واحد قد يُفسد فهارس
النصوص بسبب اختلاف ترتيب المحارف. فالانتقال يتطلّب `pg_dump` ثمّ استعادة،
لا تبديل صورة فحسب.

## 9. حدود الوحدة — ما لا تفعله

- **لا تعدّل بيانات.** كل استعلامات الاسترجاع للقراءة فقط؛ الكتابة
  الوحيدة هي حفظ رسائل المحادثة نفسها.
- **لا تتجاوز النطاق.** المستخدم المقيّد بحسابات معيّنة لا يصله محتوى
  خارجها، والشرط مطبَّق في جملة SQL لا بعد الجلب.
- **لا تخترع أرقاماً.** كل رقم في الجواب مأخوذ من لقطة تُبنى من القاعدة
  وتُرفق بالسؤال.
- **لا تُنفّذ ما في المنشورات.** نصوص المنشورات محتوى خارجي، ويُقال
  للنموذج صراحةً إنها بيانات لا تعليمات.

## 10. رسائل الأخطاء

| الحالة | الرسالة |
|---|---|
| المفتاح غير موجود | لم يتم ضبط مفتاح OpenAI. أضف OPENAI_API_KEY في ملف البيئة. |
| المفتاح غير صالح | مفتاح OpenAI غير صالح. تحقق من المفتاح المستخدم. |
| رصيد غير كافٍ | رصيد OpenAI غير كافٍ أو تم تجاوز الحد المسموح. |
| النموذج غير موجود | النموذج المحدد غير متاح في حسابك. جرّب gpt-4o-mini. |
| فشل الاتصال | تعذر الاتصال بخدمة OpenAI. حاول مرة أخرى لاحقًا. |
| تجاوز الحدّ الزمني | استغرقت المعالجة وقتًا طويلًا. حاول مرة أخرى. |
| تجاوز حدّ الأسئلة | تجاوزت حدّ أسئلة المساعد في هذه الساعة (40). حاول لاحقاً. |
