# من يرى ماذا

## الأدوار

| الدور | يرى |
| --- | --- |
| **مستخدم عادي** | المنشورات · الإحصاءات · المنصات · التقارير · اللوحات · المساعد |
| **مشرف** | ما سبق + دليل الحسابات · المقارنة · **غرفة العمليات** · لوحة الإدارة والاستخراج والمراجعة والتصنيف |
| **مدير النظام** | ما سبق + المستخدمون والإعدادات |
| **المالك** | كل شيء |

## ما أُخفي عن المستخدم العادي

**غرفة العمليات** و**دليل الحسابات** (ومعه **مقارنة الحسابات**). كلتاهما
شاشة مشغّل لا شاشة قارئ: الأولى تعرض ما يجري الآن وما تعثّر، والثاني يعرض
إعدادات الرصد ومصادره.

وغرفة العمليات صارت لها صلاحيتها `ops.view` بدل أن تُعلَّق على «اطلاع
المنشورات» — فكان يراها كلُّ من يرى منشوراً.

**ما لم يُمسّ**: اسم الحساب يبقى ظاهراً على المنشور وفي أبرز الحسابات —
ذاك بيانٌ في المنشور لا تصفّحٌ للدليل. لكنّه يصير نصّاً لا رابطاً لمن لا
يملك الدليل، فالرابط الذي يقود إلى باب مغلق أسوأ من غيابه.

## الحارس في الخادم لا في القائمة

قائمة التنقّل تُصفّى بالصلاحيات، وهذا **لا يكفي**: إخفاء الرابط يُخفي الباب
ولا يُغلقه، ومن يكتب المسار في شريط العنوان يدخل.

وقد كانت ثلاث شاشات بلا حارس أصلاً — غرفة العمليات والحسابات والمقارنة —
واثنتا عشرة أخرى تتّكل على حارس المنطقة وحده. فصار لكل شاشة في التنقّل
حارسٌ باسم صلاحيتها:

```tsx
const user = await getSession();
if (!can(user, PERMISSIONS.OPS_VIEW)) notFound();
```

و`notFound` لا `redirect`: الشاشة التي لا يملكها المستخدم يجب ألّا يعرف
أنها موجودة أصلاً.

## ثلاث طبقات، لا واحدة

| الطبقة | ماذا تفعل | أهي حدٌّ أمني؟ |
| --- | --- | --- |
| قائمة التنقّل | تُخفي ما لا يملكه | لا — تجميل |
| `useCan` في العميل | تُخفي رابطاً لا يقود إلى شيء | لا — تجميل |
| حارس الصفحة + `requirePermission` في كل مسار | يمنع الدخول والقراءة | **نعم** |

الطبقتان الأوليان تُجمّلان ما يراه من يملك الصلاحية. والحدّ في الثالثة
وحدها، ولذلك يفحصها `npm run verify:access`.

## الفحص

```bash
npm run verify:access   # ١١ فحصاً: الأدوار، وحارس كل شاشة في التنقّل
npm run verify:scope    # حصر البيانات بنطاق المستخدم — يحتاج خادماً يعمل
```

`verify:access` يقرأ المصدر ولا يحتاج خادماً. وهو يوجد لأن الخلل من النوع
الذي لا يظهر في تصفّح عاديّ: من يملك الصلاحية يرى كل شيء يعمل، ومن لا
يملكها لا يرى الرابط فلا يجرّب.
