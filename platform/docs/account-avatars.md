# صور الحسابات

الدائرة التي تحمل حرفاً واحداً ليست تصميماً مقصوداً بل حالةَ «لا صورة».
وهذه المستندة تقول من أين تأتي الصورة، ولماذا قد لا تأتي، وكيف تُجلب لما
استُخرج قبل أن يوجد جلبُها.

## من أين تأتي

ثلاثة مصادر، بهذا الترتيب:

1. **الاستخراج** — بعد كل تشغيل، يُقرأ ما أرجعه المشغّل وتُكتب الصورة على
   الحساب مع عدد المتابعين.
2. **سكربت العيّنات** — يقرأ عيّنات التشغيلات المحفوظة سابقاً، فيُغني عن
   إعادة استخراجٍ لمجرّد صورة.
3. **يدوياً** — حقل «رابط صورة الحساب» في نموذج تعديل الحساب، بمعاينة
   بجانبه.

## البحث عن الصورة نمطٌ لا قائمة

أوّل محاولة كانت قائمة أسماء حقول محتملة (`profilePicture`،
`ownerProfilePicUrl`، …) وسقطت في أوّل تشغيل حقيقي: لكل مشغّل تسميته، وهي
تتغيّر بين إصداراته. فصار البحث على نمطين:

- **مفتاحٌ** فيه `profile` أو `avatar`، أو يبدأ بـ`owner`/`author`/`user`/`page`
  متبوعاً بما يدلّ على صورة.
- **أو مفتاحٌ عامّ** (`picture`, `image`, `url`…) **داخل فرع الحساب** —
  `author.picture` صورةُ صاحبِ المنشور بلا لبس، فالفرع قاله.

وهو عكس البحث عن وسائط المنشور تماماً: ذاك يتخطّى كل فرع اسمه `profile` أو
`avatar` عمداً — لأن صورة الحساب ليست صورة المنشور، ووقوعها مكانها كان
عطباً — وهذا يلتقط ذلك الفرع وحده. فالبابان لا يتداخلان.

والحارس الأخير `isMediaUrl`: `author.url` رابطُ صفحةٍ لا ملف، فيُرفض قبل أن
يصل. ولذلك يجوز قبول `url` داخل فرع الحساب أصلاً.

## جلب ما فات

```bash
# ١) انظر ماذا وُجد — لا يكتب شيئاً
./deploy/dc.sh exec app npm run avatars:backfill

# ٢) احفظ
./deploy/dc.sh exec app npm run avatars:backfill -- --confirm
```

يقرأ `rawSample` — أوّل ثلاثة عناصر من كل تشغيل كما وصلت من المشغّل — لآخر
خمس تشغيلات لكل حساب. لا يكلّف طلباً واحداً على المزوّد.

| الخيار | ماذا يفعل |
| --- | --- |
| *(بلا خيارات)* | عرضٌ فقط |
| `--confirm` | الحفظ |
| `--all` | يشمل من له صورة محفوظة (لتحديثها) |
| `--keys` | **تشخيص**: يطبع مفاتيح الصور الموجودة في العيّنة |

## حين لا تظهر صورة

الفشل هنا صامت بطبعه: حسابٌ بلا صورة لا يقول إن كان المشغّل لم يُرسلها أم
أرسلها باسمٍ لا يعرفه النمط. و`--keys` تُجيب ذلك:

```bash
./deploy/dc.sh exec app npm run avatars:backfill -- --keys
```

تطبع لكل حساب بلا صورة **مفاتيح الصور الموجودة فعلاً في عيّنته**. فإن ظهر
فيها مفتاحٌ يحمل صورة الحساب ولم يلتقطه النمط، أرسِل السطر ويُوسَّع النمط.
وإن كانت العيّنة لا تحمل صورةً أصلاً، فالمشغّل لا يُرجعها — والحلّ حينها
الحقل اليدوي.

الأسباب الأخرى:

- **لا عيّنات محفوظة** — الحساب لم يُستخرج منه بعد، أو استُخرج قبل أن تُحفظ
  العيّنات.
- **الرابط موجود وفشل تحميله** — الصور الشخصية على شبكات التوصيل تنتهي
  صلاحيتها. والحرف يظهر تحتها تلقائياً بلا دائرة فارغة، وإعادة الاستخراج
  تجدّد الرابط.
