# قاعدة البيانات المحلية/المشتركة 📦

خادم صغير يخزّن كل المنشورات المستخرجة والمرصودة في **PostgreSQL** —
تراها كل الأجهزة والمتصفّحات التي تتّصل بنفس الخادم، وتبقى محفوظة حتى
عند نشر الخادم على استضافة سحابية وإعادة نشره لاحقاً (خلافاً لملف على
القرص يُمحى مع كل نشر هناك).

## المتطلبات

1. [Node.js](https://nodejs.org) — أي إصدار حديث. للتحقق: `node -v`.
2. خادم **PostgreSQL** يعمل — إمّا على جهازك (للتطوير)، أو خادم مُدار
   جاهز (Render، Railway، Supabase، إلخ) عند النشر الفعلي.

### تثبيت PostgreSQL محلياً (مرّة واحدة فقط)

| النظام | الأمر |
|---|---|
| **ويندوز / ماك** | نزّل المثبّت من [postgresql.org/download](https://www.postgresql.org/download/) وشغّله بإعداداته الافتراضية |
| **لينكس (Ubuntu/Debian)** | `sudo apt-get install postgresql` |

بعد التثبيت، أنشئ قاعدة البيانات والمستخدم **مرّة واحدة** (من طرفية/Terminal):

```bash
# لينكس/ماك — نفّذ هذا كمستخدم postgres:
sudo -u postgres psql -c "CREATE ROLE fbx WITH LOGIN PASSWORD 'fbx_local_dev' CREATEDB;"
sudo -u postgres psql -c "CREATE DATABASE fbx_media OWNER fbx;"
```

على ويندوز نفّذ الأمرين نفسيهما من **SQL Shell (psql)** الذي يثبَّت مع
PostgreSQL (بلا `sudo -u postgres`، فقط سجّل الدخول بالمستخدم الذي
أنشأه المثبّت).

هذا يطابق الإعداد الافتراضي الذي يفترضه `server.js` إن لم تضبط شيئاً
آخر. لأي إعداد مختلف (اسم قاعدة، مستخدم، كلمة مرور، خادم مُدار عن بُعد)
اضبط متغيّر البيئة `DATABASE_URL` قبل التشغيل بدل الاعتماد على الافتراضي:

```bash
# مثال محلي بإعداد مختلف
export DATABASE_URL="postgres://user:pass@127.0.0.1:5432/my_db"

# مثال خادم مُدار (Render يعطيك هذا الرابط جاهزاً من صفحة الـ Postgres)
export DATABASE_URL="postgres://user:pass@dpg-xxxx.render.com/dbname"
```

على ويندوز استعمل `set DATABASE_URL=...` بدل `export`.

## التشغيل

| النظام | الطريقة |
|---|---|
| **ويندوز** | اضغط مرتين على `START-DATABASE.bat` |
| **ماك / لينكس** | نفّذ `bash run.sh` أو `node server.js` |

أوّل تشغيل يجلب حزمة `pg` تلقائياً (`npm install`) — يحتاج اتصالاً
بالإنترنت مرّة واحدة فقط. إن تعذّر الاتصال بقاعدة البيانات يوضّح الخادم
عنوان الاتصال المُستعمَل وسبب الفشل بالتحديد بدل الإغلاق دون تفسير.

> **ملاحظة:** ملف `.bat` مكتوب بالإنجليزية عمداً وباسم إنجليزي — راجع
> التعليق داخله للسبب. لا تُعِد تسميته بالعربية.

اترك النافذة مفتوحة — الخادم يعمل على `http://localhost:3300`.

## الربط بالموقع

1. افتح الموقع (الصفحة الرئيسية أو صفحة الرصد).
2. في قسم **«قاعدة البيانات المحلية»** اضغط **«🔌 فحص الاتصال»**.
3. عند ظهور 🟢 يبدأ الحفظ التلقائي:
   - الصفحة الرئيسية: كل استخراج يُحفظ تلقائياً، وزر «💾 حفظ في قاعدة البيانات» للحفظ اليدوي.
   - صفحة الرصد: كل منشور جديد ترصده الدورات يُحفظ تلقائياً.

التكرار مستحيل — كل منشور يُخزَّن مرة واحدة (حسب رابطه) وتُحدَّث أرقام تفاعلاته فقط.

## واجهة الـ API

واجهة الـ API **لم تتغيّر** رغم تبديل المحرّك — أي كود يستهلكها (بما في
ذلك `results.html`) لا يحتاج أي تعديل.

| الطلب | الوظيفة |
|---|---|
| `GET /api/health` | حالة الخادم وعدد المنشورات |
| `POST /api/posts` | حفظ منشورات `{posts:[...]}` |
| `GET /api/posts?limit=&offset=&q=` | جلب المنشورات من الأحدث للأقدم مع بحث اختياري |
| `GET /api/stats` | إحصائيات إجمالية |
| `DELETE /api/posts` | مسح كل المنشورات |

للاستعلامات المتقدمة استعمل أي عميل PostgreSQL عادي (psql، DBeaver،
TablePlus...) على نفس `DATABASE_URL`.
